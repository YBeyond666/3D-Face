# 第三方资源说明

本交付包含独立的数据、适配、调度、评价与测试代码，不包含 SMIRK／DECA 上游源码、FLAME、BFM、模型权重或数据集。

运行时从用户指定的上游代码目录导入。上游提交由 `facebench fetch-upstream` 固定；训练记录实际提交和跟踪文件修改状态。授权资产仍按各自官方流程获取。

- SMIRK：https://github.com/georgeretsi/smirk，仓库代码 MIT；其 FLAME／辅助模型有单独条款。
- DECA：https://github.com/yfeng95/DECA，按官方非商业科研许可使用代码和模型。
- Multiface：https://github.com/facebookresearch/multiface，CC-BY-NC 4.0，下载器与资产按官方说明获取。
- PyTorch3D：https://github.com/facebookresearch/pytorch3d，按其 LICENSE 使用。

独立适配层没有复制上游模型或训练损失实现；用户对上游或资产的使用仍需满足其相应条件。本地核查副本位于工作区“工作暂存/代码核查”，不随代码 ZIP 分发。
